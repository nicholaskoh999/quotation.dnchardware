## Read-before-write findings

**Product × visible fields × Tab sequence (live DOM, 1440px, before):** every form ran
specification → Unit Convert → dimensions → **+ Nut, + Flat Washer, + Custom, View History** → Cost Rate,
Additional Cost, Markup, Qty, Price Mode. Dimensions per product (existing order, from the DOM):

| Product | Dimension fields |
|---|---|
| Sag Rod | Diameter, Thread Length, Length |
| Stud | Diameter, L |
| Anchor Bolt | Diameter, L, TL |
| U-Bolt | Pipe Size, Diameter, ID, IH, Thread Length, Total Length |
| SQ U-Bolt | Diameter, OH, W, Thread Length, Total Length |
| L Bolt / L Bolt 45° | Diameter, L, W, Thread Length, Total Length |
| J Bolt | Diameter, H, ID, S, Thread Length, Total Length |
| Plate | Length, Width, Thickness, hole options |
| Welding Anchor Set | anchor (material, size type, size, Ø, L, TL, qty/set), base plate (L, W, T, holes, qty/set), triangle plate (L, H, CL, CH, T, qty/set) |
| Others | product name, material, size type, weight mode, Ø / L or dimension text |

Total Length (U / SQ U / L / L45 / J) is an **auto-calculated input that accepts a manual override**
(`oninput calc…(type,true)`; L Bolt 45° requires it). It is not read-only today; R2.3 keeps it exactly so.

**Phone (402px, before):** product picker 11 large buttons (318px), every field one per row, form starting ~1,290px down;
J Bolt form 1,401px tall.

**Pricing (Session F):** one engine — `resolvePriceMode` — used by every product calc, Quick Add rows, WAS, history
reuse; Sag Rod `round05`, others `roundCustom10`. Accessories were added after the bolt was rounded (Stage 0B /
`a173510`). Saved items carry boltUnitPrice / accessoryUnitPrice / finalUnitPrice; reopen restores them; `dcPaKeepSaved`
keeps a saved price on an Update that changes nothing price-affecting. New Sag Rods default to No Round in the form
and in Quick Add (`dcDefaultPriceMode`).

**PWA shell (Session E):** `companies.php` never defined `--sab` and had no `viewport-fit=cover`; its CSS for
`html.kb-open` existed but nothing set it.

### Session F — owner contract override (recorded)

Old (Stage 0B / `a173510`): `Round(Base) + Accessories`. New (R2.3): `Round(Base + Accessories)` with the existing
engine, once. Owner example (Sag Rod, Auto): raw 7.8511, accessories 0.26 → old 8.11, **new Round(8.1111) = 8.10**.
The bolt component becomes final − accessories (e.g. 7.84), so final = bolt + accessories still holds everywhere.
Unchanged: no accessories, No Round, Manual Price, Sag Rod default No Round, zero-price confirmed proposals (add 0).
History: items without `autoRoundStage` reopen, print, send and Update (nothing price-affecting changed) exactly as
saved; only an edit of their pricing re-prices them under R2.3.
