## Decisions worth the Owner's eye

- **#09 wording.** 中文 dimension labels are now the DNC code plus the Chinese word: Ø 直径, TL 牙长,
  L 长度 (mm), W 宽度, H 高度, T 厚度; 总长度 (J / U Bolt calculated length — no code, so none added);
  孔径; Markup reads "Markup %" in both languages (the column label only; "Markup 0%" lines unchanged).
  An earlier round had approved "dimension labels stay English" (suite 30); the R2.5 instruction
  supersedes it and suite 30 now checks the new pattern.
  **Kept:** "Size 规格" and "螺纹 Size" — earlier owner-approved wording shared with Quick Add and its
  prompts, and "规格类型" is on the banned-wording list (suite 45). **Not changed:** the optional
  triangle-plate "Cut Length / Cut Height" (no DNC code, Chinese term uncertain) — Owner to decide.
- **#07 Step 4** keeps R2.3's single row of Print / WhatsApp / Copy / Copy + Weight (suite 70) — a 2 × 2
  grid would have added height. Columns are now sized to their labels; at 320px "WhatsApp" and
  "Copy + Weight" no longer spill (they did at baseline). At 320px Print / Copy are 41px wide.
- **#17** chose the switch (not a collapsible panel): one card at a time from 600 to 1279px, with the
  item count and total always on the switch. It also fixes a sideways scroll at 1180px (iPad Air
  landscape, 32px) and 1200px (12px) where two columns no longer fitted.
- **#10** the phone Quick Open label is visually hidden but remains the field's label for assistive
  technology; the placeholder still reads Q-2026-0001.

## Out of scope — recorded, not changed

**Issued By is not restored when a saved quotation is loaded.**

- Reproduce: Quotation → Edit Details → Issued By = DNC HARDWARE SDN. BHD. → add an item → Save →
  Saved → Load that quotation. Issued By shows "— No company header —".
- Expected: the saved quotation's Issued By comes back.
- Actual: it is kept only in the browser's unsaved draft (`dc_quote_unsaved_draft_v1`); it is never
  sent with the quotation — `getQI()` has no issued_by, `api.php save_quotation` has no field for it,
  and the quotations table has no column.
- Suspected component: save payload (`getQI` / save path in index.php), `api.php`, the DB schema.
- Risk: a reprinted saved quotation can lose its company header; Print / WhatsApp themselves read the
  live field correctly.
- Proposed fix (future round, needs schema approval): add a nullable `issued_by` column, send and
  return it, restore it on load; old quotations load as "no header".
